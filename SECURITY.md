# Security Policy

## Reporting

If you discover a security issue, do not open a public exploit issue.

Report it privately to the maintainers with:

- affected files or scripts
- reproduction steps
- impact summary
- suggested fix if known

## Scope Notes

This repository is a local protocol seed with no hosted service, no supplier routing, and no account system.

Security issues are still relevant for:

- schema validation bypasses
- unsafe file handling
- misleading approval or guardrail behavior
- unintended external communication
