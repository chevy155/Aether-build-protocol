## Building a local-only machine-to-machine print transaction sandbox

This draft post walks through a protocol experiment: how to model a designer-to-shop manufacturing flow without turning it into a live procurement system.

The Aether sandbox creates structured request artifacts, simulated quote responses, deterministic machine responses, and a provenance trail while refusing external actions.

Key guardrail: human approval remains mandatory before anything that would leave the repository.
