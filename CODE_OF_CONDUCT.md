# Code of Conduct

This project follows the Contributor Covenant spirit: be respectful, direct, and constructive.

## Expected Behavior

- act in good faith
- focus criticism on ideas and implementation, not people
- keep discussion factual and professional
- respect project scope and safety guardrails

## Unacceptable Behavior

- harassment or abusive language
- personal attacks
- bad-faith derailment
- encouraging unsafe or deceptive protocol behavior

## Enforcement

Project maintainers may remove comments, close issues, or block contributions that violate this code of conduct.
