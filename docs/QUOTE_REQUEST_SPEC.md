# Quote Request Spec

The Quote Request is a normalized request-for-quote contract derived from a validated Build Packet.

Required fields:

- `quote_request_id`
- `project_id`
- `scope_summary`
- `requested_quote_categories`
- `required_capabilities`
- `deliverables`
- `location_context`
- `desired_timeline`
- `required_response_fields`
- `assumptions_to_confirm`
- `exclusions_to_state`
- `risk_questions`
- `human_approval_required`

The Quote Request must make clear that the request is for review and quoting only.
