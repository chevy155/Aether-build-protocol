# Build Packet Spec

The Build Packet is the canonical description of a physical project.

Required fields:

- `project_id`
- `project_name`
- `project_type`
- `project_description`
- `design_files`
- `geometry_summary`
- `bom_items`
- `material_specs`
- `finish_requirements`
- `dimensions`
- `tolerances`
- `site_conditions`
- `location_context`
- `quote_categories`
- `capability_requirements`
- `install_scope`
- `licensed_trade_required`
- `code_review_required`
- `permit_review_required`
- `safety_notes`
- `unknowns`
- `assumptions`
- `human_approval_required`

The Build Packet must preserve what is known, what is unknown, what is risky, and what requires licensed or code-aware review.
