# Business Model

## Open-Core Model

The protocol layer should remain open enough for broad adoption.

## Free Infrastructure Layer

- schemas
- docs
- validator
- reference examples
- basic quote request generator
- basic RFQ generator

## Future Paid Hosted Layer

- hosted validation API
- private company deployments
- audit and compliance modules
- quote routing API

## Future Adapter Revenue

- SolidWorks adapters
- Fusion adapters
- Onshape adapters
- supplier quote adapters

## Future Certification Model

- Aether Build Compatible certification
- protocol-conformant builder integrations

## Future Outcome-Ledger Analytics

- quote accuracy benchmarks
- lead-time reliability metrics
- cost variance patterns
- risk pattern analytics
- builder reliability scoring

No payments are implemented in v0.2.
