# Controlled Alpha Plan

## Alpha Users

- internal operators
- technical design partners
- fabrication-adjacent reviewers
- protocol and schema reviewers

## What To Test

- whether the Build Packet captures enough detail to be quote-ready for review
- whether unknowns and risks remain explicit
- whether the generated RFQ is clear and conservative
- whether required capability and review flags are understandable

## Feedback Questions

1. What data is still missing before you would trust this packet?
2. Which unknowns or assumptions feel too vague to quote against?
3. Which downstream protocol object should be expanded next?

## Stop Conditions

- reviewers think the protocol implies autonomous supplier contact
- safety or permit flags are missing
- licensed-trade requirements are not explicit
- generated quote requests look like approvals instead of review-only requests

## No Public Launch Yet

This is a protocol seed for controlled evaluation only. No public launch yet.
